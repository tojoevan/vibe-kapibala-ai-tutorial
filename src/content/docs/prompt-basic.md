Prompt (提示词) 是与大语言模型沟通的指令规范。编写优质的 Prompt 能够大幅减少模型的幻觉，输出精准、结构化的结果。

---

## 1. 高效 Prompt 必备四要素

一个标准的结构化 Prompt 通常包含以下核心组成部分：

1. **角色定位 (Role)**：指定 AI 扮演的身份（如 Python 资深专家、严谨的技术编辑）。
2. **任务目标 (Task)**：清晰无歧义地表述需要解决的具体问题。
3. **上下文背景 (Context)**：提供必要的输入数据或限制条件。
4. **输出格式 (Output Format)**：指定返回 JSON、Markdown 表格或特定的格式代码块。

---

## 2. 经典 Prompt 结构示例

```markdown
# Role: AI 教程技术审查员

## Task
审查下方提交的 Markdown 教程文章，指出其中的技术错误与语法不通顺之处。

## Constraints
- 仅指出错误，并提供修改建议。
- 输出格式必须使用 Markdown 表格。
- 语言风格需严谨客观。

## Input Text
"""
[在此处放入要审查的 Markdown 文本]
"""
```

---

## 3. 进阶技巧：思维链 (CoT, Chain-of-Thought)

对于复杂的逻辑推理或数学计算任务，使用 **Let's think step by step (让我们一步步思考)** 可以大幅提升正确率。

```text
问：一个水果店有 15 个苹果，卖掉了 6 个，又进货了卖掉数量的 2 倍。现在有多少个苹果？

提示词技巧：
请按步骤思考并展示解答过程：
Step 1: 计算初始数量减去卖出的数量。
Step 2: 计算新进货的数量。
Step 3: 计算最终的总结。
```

通过合理组合结构化 Prompt 与思维链，可以大幅提升 AI 在复杂工程项目中的实用性！
